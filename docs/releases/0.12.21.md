# Rift Ready 0.12.21 — Reliability and efficiency fixes

- Updates is a popup like Preferences, with close-only chrome and a dimmed background.
  Other sections remain pages; navigation and unsaved review drafts are preserved.
- Protect unreadable preferences from being overwritten and save changes atomically
  with a recovery copy that survives upgrades.
- Reuse match-detail pages and bound navigation history to reduce retained UI resources.
- Refresh stale champion summaries, reflection context and matchup references; clear
  account-bound context when disconnecting or switching accounts.
- Prevent helper restart after shutdown, stop idle mobile sender wakeups, cache rank
  artwork and the drawing canvas, and remove redundant rendering/data work.
- Keep each updater download tied to its verified signed release even when a background
  check happens simultaneously. Match-time safeguards include the loading phase.

Validation passed: 769 core checks, targeted audit and navigation regressions, settings/
UI/helper suites, publisher-signature tests, and installer upgrade/rollback from 0.12.20.
The repeated-match test retained 1 detail page instead of 20; this is a resource-usage
improvement, not a claimed in-game FPS gain. Fresh live-game integration remains unverified.

The original logo, most-played champion artwork, preferences, reviews and rank history
remain. Retired overlays and unavailable recommendations are not re-enabled. Riot/
Overwolf integration and permissions remain unresolved; no approval is claimed.

Download RiftReference-Setup.exe or use Updates in Rift Ready. The updater checks
publisher-signed metadata and installer integrity. The installer is not Windows
Authenticode-signed. The separate experimental Game Bar widget is not included.
