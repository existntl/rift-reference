# Rift Ready 0.12.18 — Player overview redesign

Rift Ready has a new blue-black and teal desktop layout, with the original logo unchanged.

- Horizontal navigation and a wide champion-art banner.
- Background artwork automatically follows your most-played champion across loaded match history.
- Redesigned profile, ranked progression, champion performance and match-summary panels.
- Clearer recent-match rows with actual item icons when available.
- Local champion/role search, queue filters and 100/50/20-match ranges.
- A champion-history browser that filters your overview when you select a champion.
- Matching rounded dropdowns and teal settings switches throughout the app.

The banner uses up to 100 loaded matches across all queues, not lifetime mastery. Artwork
downloads from Riot's static CDN and is cached locally; no account or match data is sent.
Missing history or artwork uses a neutral background, and unavailable statistics stay blank.
Search currently filters your local matches, not other players' profiles.

Upgrade preserves preferences, review notes, overlay layouts, rank history and recovery copies.
Download RiftReference-Setup.exe or open Updates in Rift Ready. Publisher-signed update
metadata protects installer integrity; the installer is not Windows Authenticode-signed.
