# Rift Ready 0.12.20 — page navigation and a cleaner feature set

- Champions, champion reference, LP history, match details, Matchups, Review and
  Updates now live in the main window. Preferences remains a modal.
- Back/Forward navigation preserves filters and review drafts. Unsaved review
  decisions are inline, with explicit Save/Discard/Keep editing actions.
- LP history shows real locally recorded points. Match detail pages show known
  final personal stats and inventory without invented timelines or predictions.
- Temporarily removed the overlay runtime/settings and unavailable public build
  recommendation entry while integrations and permissions are unresolved.
- Removes demo sessions, fixes clipped Preferences action buttons, and shortens
  the cooldown setting to "Minutes and seconds".

The original logo, most-played-champion hero art, local data boundaries and saved
preferences, reviews, rank history and recovery copies are preserved. Missing data
stays unavailable; this release does not add public player lookup, timelines or
prediction features. Riot/Overwolf integration and permissions remain unresolved.

Download RiftReference-Setup.exe or use Updates in Rift Ready. The updater verifies
publisher-signed metadata and installer integrity. The installer is not Windows
Authenticode-signed. The separate experimental Game Bar widget is not included.
