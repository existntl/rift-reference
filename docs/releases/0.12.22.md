# Rift Ready 0.12.22 — Smoother navigation and scrolling

- Reduces window-drag and match-history scrolling work by retaining unchanged
  artwork, profile, summary and title-bar pixels. Scroll updates redraw the table
  instead of the entire dashboard.
- Adds keyboard navigation and accessible statistics/actions to match history:
  arrows, Page Up/Down, Home/End and Enter/Space. Ctrl+F focuses match search.
- Shows match search only on Overview and retains filters when returning.
- Keeps Back/Forward visible on Live game and fixes clipped champion-select content
  at smaller window sizes.
- Uses consistent Champions/Matchups labels, clearer champion-section selection,
  working catalog sorting and improved Preferences/lesson accessibility labels.
- Prevents nested controls from handling a mouse-wheel action more than once.

Controlled rendering tests improved from approximately 278 to 11 ms per move/repaint
cycle and 277 to 14 ms per history-scroll update. These are offscreen UI measurements,
not game FPS or a verified live mouse/compositor result.

Validation includes 769 core checks, 42 new UX interaction checks, existing dashboard,
navigation, Preferences, update-integrity and helper regressions, plus installer
upgrade/rollback checks. Layouts were inspected at 1920x1040 and 1280x950. Fresh live
League integration and actual screen-reader use remain unverified.

The original logo, most-played champion background, saved preferences, reviews, rank
history and recovery copies are preserved. Preferences and Updates remain popups.
Retired overlays and unavailable build integrations remain disabled; no Riot or
Overwolf approval is claimed.

Download RiftReference-Setup.exe or use Updates in Rift Ready. The updater verifies
publisher-signed metadata and installer integrity. The installer is not Windows
Authenticode-signed. The experimental Game Bar widget is not included.
