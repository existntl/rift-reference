Rift Ready 0.12.17 refreshes the desktop interface in the existing charcoal and teal palette.

- Settings now use compact pill switches with clear on/off states.
- Dropdowns have rounded triggers, detached dark menus, selected-row checkmarks, keyboard navigation, and type-to-select.
- Champion select uses compact roster cards, highlights your pick, and shows team champion-tag counts.
- Live match roster cards have clearer separation.
- Builds & runes has clearer tabs, selected build cards, and matching dropdowns.

Existing preferences, saved reviews, loadout selection, and update safeguards are preserved.

Download and run RiftReference-Setup.exe, or use Updates in Rift Ready. The installer does not require a .NET SDK or Electron runtime.
